# Product walkthrough

Use demo mode for a reproducible walkthrough. Prices and hotel coordinates are
simulated, and cashback is an estimate.

1. Follow [the runbook](runbook.md) to start the app.
2. In **Your trip**, enter Boston, dates, nights and a budget. Choose a location
   preference and select **Find my stay**.
3. Open the recommended stay's details. Compare the room rate, taxes, instant
   discount, upfront payment and estimated net cost. Review alternatives.
4. Open **Add an offer**. Paste a promotion, choose its platform and currency,
   and select **Analyze offer**.
5. Review the extracted conditions and source excerpts. Check the price preview
   on the same hotel snapshot before applying the offer.
6. Open **Inside TripStack** to inspect the actual extraction method and model
   diagnostics. A fallback result must be identified as a fallback.

Results depend on the input, objective and eligible offers. Confirm the current
on-screen values before quoting any totals. Use the inference check to confirm
that the local model can generate a response, not just list installed models.
